# **App Name**: xIDFI Wallet

## Core Features:

- Financial Product Aggregation: Access a range of financial products and services such as loans, term deposits, and mutual funds. Each can be accessed by url redirects. Users will use URLs to set up subscription managment.
- Tap and Pay: Enable users to add or remove cards for contactless payments. Send and receive payments via near-field communication. Links open web-based payment processing applications.
- Loyalty Point Management: Aggregate loyalty points from various merchants and redeem rewards, facilitated through unique URLs provided by the merchants.
- Transaction Categorization: Automatically categorize recent transactions for easy expense tracking. LLM "tool" to assess transactions for accurate classification.
- Decentralized Digital Identity Creation: Allow users to create and manage their decentralized digital identity.
- Credential Management: Enable users to claim, verify, and manage their digital credentials.
- Zero-Knowledge Proof Generation: Generate zero-knowledge proofs for secure and private verification.

## Style Guidelines:

- Primary color: Strong purple (#6200EE) for a modern, trustworthy feel, referencing themes of royalty, dignity, and importance.
- Background color: Light gray (#F5F5F5), a desaturated version of the primary color.
- Accent color: Teal (#1DE9B6) for interactive elements, offering a fresh contrast and contemporary touch.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use clean, minimalist icons to represent financial products, services, and identity credentials.
- Employ a clear, intuitive layout with a focus on easy navigation and readability.
- Incorporate subtle animations and transitions to enhance user experience.
